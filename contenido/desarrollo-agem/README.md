# Desarrollo matemático mediante AGEM

## 1. Propósito

Esta carpeta reunirá el desarrollo de los contenidos matemáticos de UCMI. Cada tema se estudiará y documentará de manera independiente, una vez que hayamos acordado su ubicación y alcance dentro del currículo.

## 2. Principio de trabajo

El desarrollo debe partir de necesidades matemáticas que den sentido a la construcción del conocimiento.

No se trata únicamente de presentar definiciones, fórmulas o procedimientos terminados. Buscaremos comprender qué problemas hacen necesario un concepto, cómo puede construirse una teoría para abordarlos y cómo se desarrollan algoritmos que permitan resolver situaciones relacionadas.

## 3. Organización de los materiales

Los archivos se crearán progresivamente conforme acordemos la estructura curricular.

Cada archivo deberá identificar claramente:
- El tema que se estudia.
- Su relación con el currículo.
- Los conocimientos previos necesarios.
- Las necesidades matemáticas que motivan su estudio.
- Las ideas y relaciones que se deben construir.
- Los procedimientos y algoritmos que se desarrollarán.
- Los problemas y aplicaciones que permitirán validar el aprendizaje.

Esta lista es una propuesta inicial de documentación; no pretende imponer una estructura oficial del método AGEM. Su organización se ajustará a las decisiones que tomemos durante el proyecto.

## 4. Validación del contenido

Antes de incorporar un desarrollo al material definitivo de la plataforma, revisaremos:
- La exactitud matemática.
- La coherencia del razonamiento.
- La claridad de las explicaciones.
- La validez de los procedimientos.
- La relación entre la necesidad inicial y el conocimiento construido.
- La capacidad del estudiante para aplicar lo aprendido en problemas nuevos.

## 5. Estado actual

La carpeta está preparada para recibir los desarrollos matemáticos. El contenido se incorporará progresivamente, después de analizar y acordar el currículo de UCMI.
